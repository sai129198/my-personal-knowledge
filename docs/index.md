## 📖 使用指南

### 本地构建

```bash
# 安装依赖
pip install mkdocs-material

# 本地预览
mkdocs serve

# 构建站点
mkdocs build

# 部署到 GitHub Pages
mkdocs gh-deploy
```

### 内容更新

知识库采用 **持续更新** 模式：

1. 本地编辑 Markdown 文件
2. `git add` + `git commit`
3. `git push origin main`
4. GitHub Actions 自动构建部署
