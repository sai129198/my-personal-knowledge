## 核心产品与技术

### 1. Semantic Fusion™（语义融合）

Jedify 的核心技术，是一个**自主构建的上下文图谱（Context Graph）**：

- **功能**: 将企业业务逻辑与数据融合为单一的上下文层
- **特点**:
  - 超越传统的表和元数据，为 AI Agent 提供真正的业务上下文
  - 自主映射抽象概念（如"流失客户"）到实际的表、日志和 API
  - 持续学习和进化，随业务场景变化而自适应
  - 支持跨数据孤岛的上下文推理

### 2. 平台组件

| 组件 | 功能 |
|------|------|
| **Semantic Fusion™** | AI-ready 上下文数据层 |
| **Data Agents** | 基于上下文的自主推理 |
| **Embedded AI Analytics** | 为客户提供 AI 能力 |
| **Data & Knowledge Connectors** | 原生数据连接器 |
| **AI Applications** | 基于 Semantic Fusion™ 的上下文感知分析 |
| **MCP & Integrations** | 客户面向的上下文分析 |
| **Governance** | AI 驱动的企业知识治理 |

### 3. 关键特性

- **自主适应**: 自动映射所有数据类型，随数据源、模式或定义变化而更新
- **模型无关**: 不绑定特定模型提供商，支持跨任何模型工作
- **上下文智能**: 让 Agent 基于企业术语、KPI 和目标进行可扩展的推理
- **动态语义层**: 融合业务逻辑与数据的动态语义层

## 解决的核心问题

### 企业 AI 面临的挑战

1. **数据孤岛**: 企业拥有数十到数百个 SaaS 工具，每个都有自己的数据和 UI
2. **上下文缺失**: 现有 Agent 解决方案缺乏对业务的深度理解
3. **手动维护**: 团队需要手动编写提示、维护 markdown 文件和技能
4. **供应商锁定**: 模型提供商提供的上下文解决方案存在利益冲突

### Jedify 的解决方案

- 构建**自主的上下文图谱**，连接所有企业数据
- 让 AI Agent 像经验丰富的员工一样理解业务
- 自动链接不同系统中的相关数据（如 Zendesk 工单与 CRM 交易阶段）
- 提供独立于模型提供商的语义层

## 市场定位

Jedify 将上下文图谱定位为：

> **"对于 Agentic AI，上下文图谱就像可观测性对于云基础设施一样重要"**

类比：

- 2018年：可观测性成为必需品

## 与相关技术的对比

### RAG vs Context Graph

| 特性 | RAG | Context Graph |
|------|-----|---------------|
| 数据来源 | 静态文档 | 动态企业数据 |
| 更新频率 | 手动更新 | 自主持续更新 |
| 业务理解 | 表面 | 深度业务逻辑 |
| 跨系统推理 | 有限 | 原生支持 |

### 与模型提供商方案的区别

Jedify 强调**独立性原则**：
- 上下文图谱是企业最有价值的数据资产之一
- 不应交给按 token 收费的模型提供商
- 模型无关性不是功能，而是原则
