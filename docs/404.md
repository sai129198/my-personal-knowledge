# 404 - 页面未找到

您访问的页面不存在。

<script>
// 自动重定向：如果 URL 以 .md 结尾，去掉 .md 并跳转
(function() {
    var path = window.location.pathname;
    if (path.endsWith('.md')) {
        var newPath = path.slice(0, -3);
        if (!newPath.endsWith('/')) {
            newPath += '/';
        }
        window.location.replace(newPath);
    }
})();
</script>

**可能的原因：**

1. **链接后缀错误** — 如果您手动输入了 `xxx.md`，请改为访问 `xxx/`
2. **页面尚未创建** — 该内容可能还在规划中
3. **链接已失效** — 内容可能已被移动或重命名

**建议操作：**

- [返回首页](..)
- 使用顶部搜索框查找内容
- 通过左侧导航栏浏览板块
