# LLM 预训练基础

> **一句话定位**：预训练是大语言模型的基石——理解数据、模型、训练流程的核心原理。

---

## 1. 预训练概述

### 1.1 什么是预训练

预训练（Pretraining）是在大规模无标注文本数据上训练语言模型，使其学习通用的语言表示和知识。预训练后的模型可以通过微调或提示工程适应各种下游任务。

**核心思想**：
```
预训练（通用知识） + 微调/提示（特定任务） = 强大的 AI 应用
```

### 1.2 预训练 vs 微调

| 维度 | 预训练 | 微调 |
|------|--------|------|
| **数据** | 大规模无标注数据（TB 级） | 小规模标注数据（GB 级） |
| **目标** | 学习通用语言表示 | 适应特定任务 |
| **计算** | 需要大量计算资源 | 相对较少的计算资源 |
| **时间** | 数天到数周 | 数小时到数天 |
| **参数更新** | 全部参数 | 部分或全部参数 |

### 1.3 预训练的发展

| 时间 | 里程碑 | 关键特征 |
|------|--------|----------|
| 2018 | GPT-1 / BERT | 引入 Transformer 架构 |
| 2019 | GPT-2 / RoBERTa | 扩大模型和数据规模 |
| 2020 | GPT-3 | 175B 参数，涌现能力 |
| 2022 | Chinchilla | 最优计算效率的 Scaling Laws |
| 2023 | LLaMA | 开源高效预训练 |
| 2024 | GPT-4 / Claude 3 | 多模态、长上下文 |

## 2. 预训练数据

### 2.1 数据来源

| 类型 | 示例 | 占比 |
|------|------|------|
| **网页数据** | Common Crawl、C4 | 60-80% |
| **书籍** | BooksCorpus、Gutenberg | 10-15% |
| **学术论文** | arXiv、PubMed | 5-10% |
| **代码** | GitHub、Stack Overflow | 5-15% |
| **百科** | Wikipedia | 3-5% |
| **对话数据** | Reddit、论坛 | 2-5% |

### 2.2 数据质量评估

**质量指标**：

| 指标 | 说明 | 评估方法 |
|------|------|----------|
| **语言质量** | 语法正确性、流畅度 | 语言模型困惑度 |
| **信息密度** | 信息含量 | 去重后的熵 |
| **毒性/偏见** | 有害内容比例 | 分类器检测 |
| **重复度** | 内容重复程度 | MinHash、SimHash |
| **格式质量** | HTML 清理程度 | 结构化程度 |

### 2.3 数据清洗流程

```
原始数据
  ├── 语言识别 → 过滤非目标语言
  ├── 质量评分 → 过滤低质量内容
  ├── 去重处理 → 去除重复/近似重复
  ├── 敏感过滤 → 去除 PII、有害内容
  ├── 格式标准化 → 统一编码、清理 HTML
  └── 最终数据集
```

**去重策略**：
- **精确去重**：完全相同的文档
- **模糊去重**：相似度 > 阈值的文档（MinHash + LSH）
- **段落级去重**：去除跨文档重复的段落

### 2.4 数据配比

**LLaMA 数据配比**：

| 数据集 | 占比 | 说明 |
|--------|------|------|
| Common Crawl | 67% | 网页数据，经过清洗 |
| C4 | 15% | 清洗后的网页数据 |
| GitHub | 4.5% | 代码数据 |
| Wikipedia | 4.5% | 百科数据 |
| Books | 4.5% | 书籍数据 |
| arXiv | 2.5% | 学术论文 |
| StackExchange | 2% | 问答数据 |

**配比原则**：
- 高质量数据源可以增加权重
- 代码数据有助于推理能力
- 学术数据提升知识准确性
- 对话数据改善交互能力

## 3. 预训练模型架构

### 3.1 Transformer 架构

**核心组件**：

```python
# 简化版 Transformer 架构
class TransformerBlock(nn.Module):
    def __init__(self, d_model, n_heads):
        self.attention = MultiHeadAttention(d_model, n_heads)
        self.feed_forward = FeedForward(d_model)
        self.norm1 = LayerNorm(d_model)
        self.norm2 = LayerNorm(d_model)
    
    def forward(self, x):
        # 自注意力 + 残差连接
        x = x + self.attention(self.norm1(x))
        # 前馈网络 + 残差连接
        x = x + self.feed_forward(self.norm2(x))
        return x
```

### 3.3 位置编码

| 类型 | 说明 | 代表模型 |
|------|------|----------|
| **绝对位置编码** | 固定或可学习的位置向量 | BERT、GPT-2 |
| **相对位置编码** | 相对位置偏置 | T5 |
| **旋转位置编码 (RoPE)** | 旋转矩阵编码位置 | LLaMA、PaLM |
| **ALiBi** | 基于距离的位置偏置 | BLOOM |

**RoPE 公式**：
```
f(q, m) = q · e^(i·m·θ)
```
其中 m 是位置，θ 是频率。

## 4. 预训练目标

### 4.1 语言建模目标

**自回归语言建模（Causal LM）**：
```
目标：预测下一个词
损失：L = -Σ log P(x_t | x_<t)

示例：
输入："今天 天气 很"
目标："好"
```

**掩码语言建模（Masked LM）**：
```
目标：预测被掩码的词
损失：L = -Σ log P(x_t | x_\mask)

示例：
输入："今天 [MASK] 很好"
目标："天气"
```

### 4.2 多任务预训练

**混合目标**：
-  span corruption（T5）
-  prefix LM（UL2）
-  去噪目标（BART）

## 5. 训练流程

### 5.1 训练配置

**优化器设置**：
```python
optimizer = AdamW(
    lr=1e-4,           # 学习率
    betas=(0.9, 0.95), # 动量参数
    eps=1e-8,
    weight_decay=0.1   # 权重衰减
)

scheduler = CosineAnnealingLR(
    optimizer,
    T_max=total_steps,
    eta_min=1e-5       # 最小学习率
)
```

**训练超参数**：

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 学习率 | 1e-4 ~ 3e-4 | 初始学习率 |
| Batch Size | 1M ~ 4M tokens | 全局批次大小 |
| 训练步数 | 100K ~ 300K | 总训练步数 |
| 权重衰减 | 0.1 | L2 正则化 |
| 梯度裁剪 | 1.0 | 防止梯度爆炸 |
| Warmup | 1% ~ 2% | 学习率预热步数 |

### 5.2 训练稳定性

**常见问题与解决**：

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| **损失爆炸** | 梯度爆炸 | 梯度裁剪、降低学习率 |
| **损失 NaN** | 数值溢出 | 混合精度检查、损失缩放 |
| **收敛慢** | 学习率不当 | 调整学习率、改进初始化 |
| **过拟合** | 数据不足 | 增加数据、正则化 |

**稳定训练技巧**：
- 使用 bfloat16 或 float32 进行主权重更新
- 梯度累积增大有效 batch size
- 使用 Flash Attention 减少显存占用
- 模型并行和数据并行结合

## 6. 评估与验证

### 6.1 评估指标

**困惑度（Perplexity）**：
```
PPL = exp(-1/N · Σ log P(x_i))
```
越低越好，表示模型对文本的预测能力越强。

**下游任务评估**：
- 分类任务：准确率、F1
- 生成任务：BLEU、ROUGE
- 推理任务：MMLU、GSM8K
- 代码任务：HumanEval

### 6.2 验证策略

- **保留验证集**：从训练数据中分离
- **下游任务验证**：在代表性任务上评估
- **人工评估**：检查生成质量

## 8. 预训练最佳实践

### 8.1 数据策略

1. **质量优先**：高质量数据比大量低质量数据更重要
2. **多样性**：覆盖多种领域和风格
3. **去重彻底**：避免数据污染
4. **持续更新**：定期更新训练数据

### 8.2 训练策略

1. **从小规模开始**：先在小模型上验证配置
2. **监控训练过程**：实时跟踪损失和评估指标
3. **保存检查点**：定期保存模型检查点
4. **容错设计**：支持断点续训

### 8.3 效率优化

1. **混合精度训练**：使用 bf16/fp16 加速
2. **梯度检查点**：时间换空间
3. **Flash Attention**：优化注意力计算
4. **数据并行 + 模型并行**：扩展训练规模

---

## 9. 总结

预训练是 LLM 能力的基础：

1. **数据是关键**：高质量、多样化的数据决定模型上限
2. **Scaling Laws**：模型大小、数据量、计算量需要平衡
3. **稳定性**：大规模训练需要 careful 的工程实现
4. **评估**：多维度评估模型能力

> **关键洞察**：预训练的本质是让模型从海量文本中学习语言规律和世界知识。数据质量 > 数据数量 > 模型大小。
