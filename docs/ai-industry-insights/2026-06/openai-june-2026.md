## 一、ChatGPT 记忆系统重大升级：Dreaming V3

### 核心变化

OpenAI 推出了基于 **Dreaming V3** 的全新记忆架构，这是 ChatGPT 记忆系统自 2024 年 4 月首次发布以来最重大的升级。

**记忆系统演进时间线：**

| 时间 | 版本 | 特点 |
|------|------|------|
| 2024.04 | Saved Memories | 用户主动要求"记住"，类似记笔记 |
| 2025.04 | Saved + Dreaming V0 | 后台自动整理记忆，但不够独立 |
| 2026.06 | Dreaming V3 | 完全自主的记忆合成系统 |

### Dreaming 的核心机制

**不是存储，而是合成。**

传统记忆系统像是一个笔记本——用户写下什么，系统记住什么。但笔记本会过时、会堆积、会混乱。

Dreaming 则像是一个**持续在后台运行的整理过程**：

1. **自动策展**：从数百次对话中提取关键信息
2. **时间感知**：自动更新时效性信息（如"计划去新加坡"→"已去过新加坡"）
3. **偏好学习**：理解用户的隐性偏好（如"我喜欢野生动物摄影"→后续推荐自动过滤）
4. **上下文关联**：将分散在不同对话中的信息关联起来

### 三个评估维度

OpenAI 用三个核心指标衡量记忆质量：

1. **上下文传递（Carry forward context）**
   - 例：用户曾讨论过相机配置，后续问"我的摄影设备推荐"时自动关联
   - Dreaming V3 相比 Saved Memories 有显著提升

2. **偏好遵循（Follow preferences）**
   - 例：用户说过自己是素食主义者，后续餐饮推荐自动过滤
   - 包括显性偏好（"不要提Stan"）和隐性偏好（"我住旧金山附近"）

3. **时效性保持（Stay current over time）**
   - 这是 Dreaming 最大的突破点
   - 传统系统："我在新加坡需要晚餐推荐"→两周后仍然认为用户在新加坡
   - Dreaming：自动识别时间流逝，更新状态

### 技术意义

- **计算效率**：服务 Free 用户的计算成本降低了约 **5 倍**
- **规模可行性**：使记忆系统可以扩展到数亿用户
- **质量门槛**：Free 用户版本首次达到 OpenAI 的质量标准

## 二、GPT-Rosalind：生命科学专用模型

### 定位

GPT-Rosalind 是 OpenAI 首个**垂直领域专用模型**，基于 GPT-5.5 的 agentic 编码和工具使用能力，专门针对生命科学研发优化。

### 核心能力

| 能力领域 | 具体表现 |
|---------|---------|
| 分子与蛋白质 | 分子结构理解、蛋白质折叠预测 |
| 基因组学 | 基因通路分析、变异解读 |
| 药物化学 | SAR（构效关系）、ADME 预测、先导化合物优化 |
| 科学推理 | 跨文献证据整合、实验设计评估 |
| 湿实验室 | 实验故障排查、操作流程优化 |

### 专用基准测试：LifeSciBench

OpenAI 设计了**端到端**的生命科学基准，不同于传统单一维度测试：

- **6 大工作流领域**：证据处理、分析、设计与优化、科学推理、验证与操作、转化与沟通
- **外部专家评审**：由行业和学术专家评判
- **真实场景导向**：关注"科学上有价值的工作"而非孤立任务

### 性能数据

| 基准 | 每 token 性能提升 |
|------|------------------|
| Genebench | +53.7% |
| MedChem Bench | +18.0% |
| Labworkbench | +19.6% |
| LifeSci Bench | +4.4% |

### 应用场景示例

在药物审批评估场景中，GPT-Rosalind 能够：

1. 识别微肌营养不良蛋白定量中的检测问题
2. 指出现有生物标志物与临床获益之间的逻辑缺口
3. 评估试验设计的统计学缺陷
4. 提出改进建议（如需要随机对照研究、纵向耐久性数据等）

## 三、收购 Ona：Codex 的云端持久化

### 背景

Codex 周活用户已超过 **500 万**（较年初增长 400%），从开发者工具扩展为面向更广泛人群的复杂工作自动化平台。

### 问题

Codex 最有价值的工作往往需要**数小时甚至数天**完成，但：
- 用户关闭笔记本后工作中断
- 无法跨设备查看进度
- 企业部署面临安全和治理挑战

### Ona 的价值

Ona 是一家帮助开发者将开发环境从本地迁移到云端的公司，已服务 **200 万开发者**。

**收购带来的能力：**

1. **持久化执行环境**：Agent 在云端持续运行，即使用户设备离线
2. **客户控制**：Agent 在组织自己的云环境中运行
3. **安全与治理**：满足企业的安全、凭证范围、活动日志、审核流程要求
4. **生产级部署**：从实验走向生产工作流

### 战略意义

这标志着 OpenAI 从"模型公司"向"基础设施公司"的延伸——不仅提供智能，还提供**智能运行的环境**。

## 四、OpenAI 提交 S-1：IPO 准备

### 关键信息

- OpenAI 已向 SEC 提交**保密 S-1 文件**
- 尚未决定上市时间，可能作为私营公司继续运营一段时间
- 某些事项作为私营公司处理可能更容易

### 战略背景

这是 OpenAI 进入**第三阶段**的标志：

| 阶段 | 时间 | 核心任务 |
|------|------|---------|
| 第一阶段 | 早期 | AGI 研究 |
| 第二阶段 | ChatGPT 发布后 | 产品化、部署、学习 |
| 第三阶段 | 现在 | 让先进 AI 普及、可负担、安全、有用 |

## 五、OpenAI 三大战略目标

OpenAI 明确提出了三个核心目标：

### 1. 构建自动化 AI 研究员

- 目标：到 **2028 年 3 月**，让 AI 系统承担 OpenAI 研究的**重要部分**
- 原因：对齐（Alignment）本身是困难的研究问题，需要 AI 协助迭代
- 关键：保持可操控性、问责制、与人的连接

### 2. 加速经济

- 通过加速科学进步、生产力和经济增长
- 确保收益**广泛共享**
- 每个人都应有机会分享 AI 创造的繁荣

### 3. 给每个人一个个人 AGI

- 让地球上的每个人都能从这项变革性技术中受益
- 以他们选择的任何方式

## 九、Codex 科学应用案例：黑洞模拟

### 背景

亚利桑那大学天体物理学家 Chi-kwan Chan 使用 Codex 帮助模拟黑洞周围的等离子体。

### 挑战

- 黑洞周围等离子体极度稀薄，粒子很少碰撞
- 传统模拟必须计算每个粒子的微小螺旋运动
- 即使最快超级计算机也大部分时间浪费在这些微小计算上

### Codex 的作用

1. **算法推导**：生成多种候选数学方法
2. **快速验证**：测试哪些方法有效
3. **物理可解释**：生成的数值方案可以被检查、测试、物理理解

### 关键洞察

> "我们不接受一个想法是因为来自爱因斯坦、聪明学生或 AI 模型。我们只在接受反复测试后才接受它。"

科学可能是当今 AI **最佳应用场景**之一，因为科学想法可以被严格测试。

## 十、核心观点与判断

### 1. 从"工具"到"Agent"的范式转移

OpenAI 的所有产品都在向 Agent 化演进：
- ChatGPT：从问答到长期记忆+主动服务
- Codex：从代码补全到持续运行的云端 Agent
- 企业产品：从 API 到完整的工作流自动化

### 2. 记忆是 Agent 的核心基础设施

Dreaming V3 的推出表明，OpenAI 认为**记忆能力**是区分"聊天机器人"和"真正助手"的关键。没有记忆，Agent 无法建立长期关系；有了记忆，Agent 才能从"每次从零开始"变为"越用越懂你"。

### 3. 垂直化是模型发展的必然方向

GPT-Rosalind 标志着 OpenAI 从通用模型向**垂直专用模型**扩展。生命科学只是开始，未来可能有法律、金融、工程等领域的专用模型。

### 4. 基础设施即护城河

收购 Ona、与 Oracle 合作、提交 IPO——OpenAI 正在构建**从模型到基础设施到企业服务的完整栈**。模型能力容易被追赶，但基础设施和客户关系是更深的护城河。

### 5. AGI 时间线更加紧迫

OpenAI 明确提出 2028 年让 AI 承担重要研究工作的目标，以及"给每个人一个个人 AGI"的愿景。这意味着：
- 技术迭代速度将继续加快
- 对齐和安全问题更加紧迫
- 需要国际协调机制
