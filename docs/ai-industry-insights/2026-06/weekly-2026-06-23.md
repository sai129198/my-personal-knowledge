## 📊 技术进展

### 模型与算法

#### GLM-5.2 架构创新
- **DeepSeek Sparse Attention (DSA)**：稀疏注意力机制，78 层混合模式（21 Full + 57 Shared/Skip）
- **IndexShare**：每 4 层共享 indexer，1M 上下文下每 token FLOPs 降低 2.9×
- **MoE 架构**：256 路由专家 + 1 共享专家，每 token 激活 8 个专家，Sigmoid 路由评分
- **MTP 推测解码**：接受长度提升 20%，配合 DSA 实现高效长文本生成

#### 性能基准亮点
| 基准 | GLM-5.2 | 对比 |
|------|---------|------|
| AIME 2026 | **99.2%** | 超过 Claude Opus 4.8 (95.7%) |
| IMOAnswerBench | **91.0%** | 开源模型最高 |
| SWE-bench Pro | 62.1% | 接近 Claude Opus 4.8 (69.2%) |
| Terminal Bench 2.1 | **81.0%** | 开源 SOTA |

**关键洞察**：GLM-5.2 在推理任务上达到开源 SOTA，但在复杂软件工程任务（SWE-bench Pro、DeepSWE）上仍落后 Claude Opus 4.8，说明长周期 Agent 能力仍是闭源模型的护城河。

### 基础设施

#### DeepSWE 基准测试创新
- **零污染**：任务全新手写，非来自现有 GitHub PR
- **91 个仓库，5 种语言**：TypeScript (31%)、Go (30%)、Python (30%)、JavaScript (4%)、Rust (4%)
- **行为导向验证器**：测试可观察行为，接受多种正确实现
- **任务复杂度**：需 5.5× 更多代码，平均 660 行 vs SWE-bench 的 120 行

#### RAGFlow 架构演进
- **Agent Context Engine 定位**：从独立 RAG 系统进化为 Agent 生态的核心数据层
- **三大核心组件**：Knowledge Core（高级 RAG）、Memory Layer（对话历史/用户偏好）、Tools Orchestrator（MCP/技能检索）
- **Infinity 向量数据库**：自研，支持 HNSW + LVQ/RaBitQ 量化 + LSG 图优化

### 开源生态
- **GLM-5.2 MIT 开源**：中国大模型厂商首次以完全开源方式发布顶级能力模型
- **RAGFlow 快速增长**：入选 GitHub 最快增长开源项目

## 💡 本周观察与思考

### 值得关注的信号

1. **开源模型能力逼近闭源**
   - GLM-5.2 在推理任务（AIME 99.2%）上已接近甚至超过部分闭源模型
   - 但在复杂软件工程（DeepSWE 46.2% vs Claude 58%）上仍有差距
   - **判断**：开源模型在"考试型"任务上追赶迅速，在"实践型"长周期任务上仍有差距

2. **评估基准成为竞争焦点**
   - DeepSWE 的发布说明行业意识到 SWE-bench 已饱和（顶尖模型分数挤在一起）
   - 新基准强调：零污染、多语言、行为导向验证、长周期任务
   - **判断**：评估基准的创新速度将决定模型能力提升的可信度

3. **RAG 从独立技术进化为 Agent 基础设施**
   - RAGFlow 的转型代表行业共识：RAG 不再是独立产品，而是 Agent 的上下文层
   - Knowledge + Memory + Tools 的三层架构可能成为标准
   - **判断**：2026 年下半年，"RAG 公司"将转型为"Agent 数据基础设施公司"

4. **中国开源模型崛起**
   - GLM-5.2 的 MIT 开源发布标志着中国模型厂商从"跟随"转向"引领"
   - 744B 参数、1M 上下文、开源 SOTA，这些指标具有全球竞争力
   - **判断**：中美 AI 竞争从"闭源 API"扩展到"开源生态"维度

### 趋势判断

- **开源 vs 闭源竞争白热化**：GLM-5.2 证明开源模型可以达到接近顶级的性能，可能迫使 OpenAI/Google 调整开源策略
- **Agent 评估成为新战场**：DeepSWE 这类长周期、复杂任务基准将取代简单问答基准，成为模型能力的主要衡量标准
- **上下文长度军备竞赛**：1M token 成为新标杆，但真正的挑战是如何有效利用长上下文（而非仅仅支持）

### 待验证的假设

- GLM-5.2 的 MIT 开源是否会引发一波基于它的衍生模型和微调模型？
- DeepSWE 是否会成为新的行业标准基准，取代 SWE-bench？
- RAGFlow 的 Agent Context Engine 定位是否能获得市场认可？
