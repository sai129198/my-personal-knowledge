## 🏢 大公司动态

### OpenAI
- **提交保密 S-1 文件**：向 SEC 提交 IPO 准备文件，可能作为私营公司继续运营一段时间，标志着进入第三阶段
- **Dreaming V3 记忆系统升级**：完全自主的记忆合成系统，自动策展、时间感知、偏好学习、上下文关联。Free 用户计算成本降低约 5 倍
- **GPT-Rosalind 生命科学专用模型**：首个垂直领域专用模型，针对分子蛋白质、基因组学、药物化学优化，在 Genebench 上性能提升 53.7%
- **收购 Ona**：Codex 周活用户超 500 万（年初增长 400%），收购 Ona 实现云端持久化执行环境，Agent 可 24/7 运行
- **OpenAI Academy 企业培训**：与 BCG、埃森哲合作，推出 AI Foundations、Applied AI Foundations、Agents and Workflows 课程体系
- **Oracle 云合作**：Oracle 客户可用现有 Universal Credits 购买 OpenAI 模型，降低企业采购摩擦
- **Codex 科学应用**：亚利桑那大学天体物理学家使用 Codex 模拟黑洞周围等离子体，生成可验证的数值方案

### Google / DeepMind
- **Gemini Omni 发布**：任意输入（文本/图像/视频/音频）生成视频输出，理解物理直觉（重力、动能、流体动力学），支持多轮编辑
- **Gemini Spark 个人 Agent**：24/7 云端运行，设置循环任务、学习新技能、创建工作流，深度集成 Workspace，通过 MCP 连接 Canva、OpenTable 等
- **第八代 TPU 双芯片架构**：TPU 8t（训练）支持百万芯片集群、121 ExaFlops；TPU 8i（推理）80% 性价比提升，延迟降低 5 倍
- **Google Flow 创意平台扩展**：从电影制作工具升级为 AI 创意工作室，集成 Gemini Omni、Flow Agent、Flow Music
- **SynthID 内容透明度**：已水印 1000 亿+ 图像和视频，OpenAI、NVIDIA、ElevenLabs 等公司采用；Pixel 10 首发 C2PA Content Credentials
- **数据规模爆发**：月处理 Token 从 2 年前的 9.7 万亿增长到 3.2 千万亿（330 倍），Gemini 应用月活从 4 亿增长到 9 亿+

### Anthropic

### 其他（Meta、Microsoft、Amazon等）

## 📊 技术进展

### 模型与算法
- **记忆成为 Agent 核心基础设施**：OpenAI Dreaming V3 证明，记忆能力（而非单纯上下文长度）是区分"聊天机器人"和"真正助手"的关键
- **垂直模型兴起**：GPT-Rosalind 标志着从通用模型向垂直专用模型扩展，生命科学只是开始，未来可能有法律、金融、工程等领域专用模型
- **多模态默认化**：Gemini Omni 的"任意输入，任意输出"代表 AI 终极形态，模态边界正在消失

### 基础设施
- **双芯片架构成为趋势**：Google TPU 8t（训练）和 8i（推理）分别优化，说明训练和推理需求差异巨大，需要专门设计
- **百万芯片集群训练**：TPU 8t 通过 Virgo Network 实现近线性扩展到 100 万芯片，使"更大模型"成为可能
- **云端持久化 Agent 环境**：OpenAI 收购 Ona 使 Agent 可在云端持续运行，即使用户设备离线

### 开源生态
- 本周无重大开源动态

## 💡 本周观察与思考

### 值得关注的信号
- **Agent 范式转移加速**：OpenAI 和 Google 同时推进 Agent 化，从"工具"到"行动伙伴"的转变正在发生
- **记忆成为新战场**：Dreaming V3 和 Gemini Spark 都强调长期记忆和持久化，这是 Agent 建立长期关系的基础
- **垂直化是模型发展的必然方向**：GPT-Rosalind 证明专用模型在特定领域可以比通用模型更专业
- **基础设施即护城河**：OpenAI（收购 Ona + Oracle 合作）和 Google（TPU 自研）都在构建从模型到基础设施的完整栈

### 趋势判断
- **2026 是 Agent 元年**：所有大厂产品都在向 Agent 化演进，个人 Agent、企业 Agent、创意 Agent 将百花齐放
- **多模态将成为默认**：不再区分"文本模型"、"图像模型"、"视频模型"，一个模型理解并生成所有模态
- **AI 经济研究将升温**：OpenAI 启动 Economic Research Exchange，说明 AI 对经济的影响已成为核心议题

### 待验证的假设
- OpenAI 的 IPO 是否会在 2026 年内完成？估值会是多少？
- Gemini Spark 的 24/7 云端 Agent 模式是否会被用户接受？隐私和安全担忧如何解决？
- 垂直专用模型（如 GPT-Rosalind）是否会改变 AI 商业模式，从通用 API 转向行业解决方案？
