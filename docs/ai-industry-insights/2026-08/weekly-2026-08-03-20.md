## 📌 本期速览

这是 AI 行业「安全与商业双线并进」的两周。安全侧，OpenAI 因旗舰模型 Astra 触及 Critical 网络安全阈值而主动暂停研发，将 7 月以来的「AI 越狱」恐慌推向新阶段；商业侧，Anthropic 交出上市以来首次季度盈利，OpenAI 则推出首个专门针对网络安全的垂直模型 GPT-5.6-Cyber，Google DeepMind 完成高层重组。而在中国，DeepSeek 于 8 月 6 日预告、8 月 13 日公布正式方案的 API 全面涨价落地，标志着国产大模型从「价格屠夫」正式转向「价值定价」，成为本期贯穿始终、也是本知识库最近两周持续跟踪的核心议题。

## 💰 一、DeepSeek API 涨价：从「价格屠夫」到「价值定价」

### 1.1 事件脉络

这是本期最贴近我们、也最值得沉淀的一条主线。8 月 6 日 DeepSeek 在开发者后台弹窗预告「计划近期整体上调 API 定价，预计涨幅较大」；8 月 13 日官方公布正式方案；8 月 17 日（北京时间）起生效。

| 时间 | 事件 |
|------|------|
| 8月6日 | 官方预告：整体大幅涨价，具体方案待定 |
| 8月13日 | 正式方案公布：首次引入**峰谷分时定价** |
| 8月17日 | 新定价生效，V4-Pro 结束测试期转正式商用 |

### 1.4 涨价原因

1. **算力供不应求**：V4-Flash 正式版单日用量一度冲到 8 万亿 Token（含 5 万亿免费额度），超过 OpenRouter 全平台 400+ 模型日均总量；8 月 4 日曾出现容量不足。
2. **商业化 + IPO 压力**：DeepSeek 已完成首轮外部融资（约 $74 亿，估值 $520 亿），筹备 2027 年 IPO，烧钱换市场的模式必须结束。
3. **V4-Pro 转正**：结束测试期，转入正式商用。

### 1.5 影响与判断

- **对开发者**：依赖低价 API 的下游应用需重新核算成本；高峰输出成本最高涨 4.5 倍（v4-pro ¥6→¥27）。
- **竞争格局**：即使涨价，DeepSeek 相对西方旗舰（GPT-5.5 $5/$30、Claude Opus $5/$25）仍便宜一个数量级以上。
- **行业信号**：智谱（年内三次涨价）、阿里、腾讯、百度均已在调价，国产大模型集体走出价格战。

> 🔍 我的判断：这是一次「健康的转向」。免费/极低价本质是资本补贴，不可持续。一个能稳定盈利的 API 提供商，才是对开发者最大的负责。真正该盯的不是「涨多少」，而是「产品力能否跟上」——V4-Pro 正式版的能力天花板才是决定这次涨价是否「物有所值」的关键。

## 🛡️ 二、OpenAI Astra 暂停：首个触发「Critical」阈值的模型

### 2.1 事件（8月7日）

OpenAI 披露，其下一代前沿模型 **Astra** 在内部安全评估中，网络安全能力强度使其「无法排除」触及 Preparedness Framework 的 **Critical（最高）风险等级**：

- Astra 可**自主识别并开发零日漏洞**，无需人工介入
- 可从高层目标出发**端到端执行网络攻击**
- 这是 OpenAI 首个触发 Critical 阈值的模型（此前 GPT-5.6 Sol 仅评 High，且已在 ARC-AGI-3 展现惊人进步）

**应对措施**：暂停非必要内部研发、转入隔离测试环境（限制网络访问）、全量监控风险行为、加码沙箱执行与权重保护、与政府及安全机构合作后再考虑发布。

> 🔍 我的判断：这接续了 7 月 Hugging Face 事件与 Anthropic「三机构入侵」审查形成的安全连锁。本质上 Astra 暂停是把 7 月的「被动发现」升级为「主动叫停」——OpenAI 在抢在失控前踩刹车。这与 7 月底 1100+ 从业者「有节奏前进」的联合声明形成呼应，AI 安全正从「理论风险」进入「研发流程的前置闸门」。

## 🔬 四、OpenAI：GPT-5.6-Cyber 与 Astra 的分叉叙事

### 4.1 GPT-5.6-Cyber 发布（8月10日）

OpenAI 推出首个**专为授权漏洞研究训练的网络安全模型** GPT-5.6-Cyber，通过「Daybreak Red」层级向 Accenture、IBM、CrowdStrike、Cisco、Cloudflare 等受审核伙伴开放，完成 95% 高级网络安全测试提示。

> 🔍 我的判断：一边暂停 Astra 的通用网络能力，一边发布专门的 Cyber 模型——这是一组耐人寻味的「分叉」：OpenAI 在把「通用模型不能碰的安全边界」与「可控、受审核的垂直安全能力」明确切分开。安全正在成为一条**产品线**，而不只是约束条件。

## 🎯 本期核心洞察

### 1. 国产大模型「价格战」正式终结

DeepSeek 涨价不是孤立事件，而是国产大模型从「烧钱抢市场」切换到「价值回收」的集体拐点。价格屠夫的时代落幕，意味着下一阶段的竞争将回归**模型能力与工程效率**本身——这才是健康的方向。

### 2. 安全从「事后审查」变成「事前闸门」

从 7 月的「被动发现越狱」（Hugging Face、Anthropic 三机构）到 8 月的「主动叫停」（Astra 暂停），AI 安全已完成一次范式升级：安全评估不再是发布后的道歉，而是研发流程中的**前置否决权**。同时，垂直安全模型（GPT-5.6-Cyber）的出现，让「安全」本身成为一条可商业化的产品线。

### 3. 商业成熟度加速分化

Anthropic 首次盈利、OpenAI 仍巨亏（2026 预计亏损 ~$140 亿）、两者都奔向 IPO——头部实验室的「商业模式赛跑」进入关键期。谁先证明可持续盈利，谁就在资本市场上占据先机。

### 4. 算力仍是终极稀缺品

DeepSeek 因「算力扛不住」而涨价、Anthropic 签下 $91 亿算力长约、AMD/Google 自研芯片竞赛——几乎所有本期大事的底层，都是**算力供给的紧张**。算力正在成为比模型参数更硬的竞争壁垒。
