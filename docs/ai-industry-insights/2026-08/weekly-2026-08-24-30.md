## 📌 本周速览

本周舞台中央是一场**「巨头生态站队」的连锁反应**。SpaceX 于 8 月 14 日完成对 Cursor（Anysphere）约 $600 亿的全股票收购、成立 SpaceXAI 部门后，OpenAI 于 8 月 28 日公开通知 SpaceX：**将终止向 Cursor 提供 OpenAI 模型**（拟定 11 月 12 日关停）——理由是无法确信 SpaceX 会在服务条款内使用其技术。与此同时，Anthropic 与 Salesforce 达成 **「Claudeforce」深度合作**（8 月 26 日），Claude 成为 Slack AI/Slackbot 与 Agentforce 的默认模型；Anthropic 还预览了面向物理世界的 **Model Hardware Standard**。企业级 AI 的「模型选边」正在从聊天室走向 CRM、代码编辑器与机器人硬件。

## 🔬 一、OpenAI：与 SpaceX 决裂，Cursor 断供

### 1.1 终止向 Cursor 提供模型（8月28日）

OpenAI 公开声明：已通知 SpaceX，打算**终止向 Cursor 提供 OpenAI 模型的合同**，拟定关停日期 **11 月 12 日**（按合同最大提前通知期，尽量延长开发者保留模型访问的时间）。

核心理由——**信任鸿沟**：

- OpenAI 无法确信 SpaceX 会「在服务条款内」使用其技术，依据是马斯克旗下公司的违约前科：
  - 收购 Twitter（现并入 SpaceX）后，公司违反了与 OpenAI 的合同条款；
  - 今年早些时候，马斯克在宣誓下承认 **xAI（现也并入 SpaceX）曾用蒸馏 OpenAI 数据训练模型**，违反了 OpenAI 的服务条款。
- 合同给了 OpenAI 在「控制权变更」后一个有限的取消窗口；随着能力升级，OpenAI 对新旗舰 **Astra** 的合规使用负有新的问责要求。

> 🔍 我的判断：这表面是「合同 + 安全合规」的冷处理，实质是**模型基础设施层面的阵营站队**。Cursor 曾是 OpenAI 模型在开发者侧最大的分发渠道之一，而它现在随收购落入 SpaceX/马斯克阵营——OpenAI 用「断供」划出了一条清晰的边界：**前沿模型能力不会流向一个既与自研模型（Grok）直接竞争、又有违约前科的生态**。这跟此前「暂停 Astra 通用能力 vs 发布 GPT-5.6-Cyber 垂直模型」是同一套逻辑的延续：安全/信任边界正在变成产品与商业博弈的核心杠杆。

## 🧭 二、Anthropic：Claudeforce 合作 + 物理世界 Agent 规范

### 2.1 Claudeforce（8月26日，与 Salesforce）

Anthropic 与 Salesforce 宣布 **「Claudeforce」** 深度合作，Claude 深度嵌入 CRM 数据与工作流。四大支柱：

| 支柱 | 内容 |
|------|------|
| Salesforce in Claude | Claude 插件，**37 个预置销售技能**（会议准备、商机健康度、管道分析等），销售无需打开 Salesforce 即可操作实时 CRM 数据 |
| Claude in Salesforce | Claude 成为 Agentforce「Atlas 推理引擎」的**默认推理模型**，驱动 Agentforce Vibes / Coworker |
| Claude across Slack | Claude 成为 **Slack AI 与 Slackbot 的默认模型**，并作为 Slack Code 创始伙伴 |
| 互相采用 | 双方互为战略客户，Salesforce 每年约 **$3 亿**投入 Anthropic tokens |

> 🔍 我的判断：这是「**AI 界面取代传统 SaaS 应用屏幕**」的一张重注。Benioff 那句「The UI is the AI」点出了本质——当推理模型成为默认工作界面，CRM/协作工具的护城河就从「功能菜单」转移到「模型 + 数据 + 治理」的结合体。这也是 Salesforce 首次把「-force」后缀用在别人家产品上，深度罕见。对 Anthropic 而言，这是在巨头生态里拿到一个**企业分发 + 数据飞轮**的立足点，与 OpenAI 失去 Cursor 渠道形成鲜明对照。

### 2.2 Model Hardware Standard 预览（8月27日）

Anthropic 开放 **Model Hardware Standard (MHS)** 的研究预览——一个让 AI Agent **安全操作物理设备**的共享规范，首批开放给科研实验室与先进制造商。

> 🔍 我的判断：这是从「软件 Agent」走向「具身/物理 Agent」的**标准化探路**。当 Agent 要操作机器人、机床、实验室设备时，光有「推理能力」不够，还需要一套「动作边界 + 安全协议」的共识——MHS 试图成为这个层级的 TCP/IP。Anthropic 在抢一个「物理世界 Agent 安全标准」的定义权，比抢单点模型能力更有长期价值。

## 🤖 三、Google DeepMind：Gemini Robotics ER 2

官方博客发布 **Gemini Robotics ER 2**，定位为机器人应用在**视频理解、工具编排、多机器人协作**上的「step change」——面向具身智能与真实机器人场景的下一代能力升级。

> 🔍 我的判断：Google 在具身方向持续加码，与 Anthropic 的 MHS 形成呼应——**「Agent 进物理世界」是本周多家实验室的共同叙事**。区别在于：Google 走「模型能力」（视频理解/多机器人协作），Anthropic 走「接口规范」（安全操作标准）。两条路线最终会汇合在「可安全部署的物理 Agent」这一终点上。

## 🎯 本周核心洞察

### 1. 模型阵营站队加速，代码编辑器首当其冲

SpaceX 收 Cursor → OpenAI 断供 → Cursor 绑定 Grok，这条链路意味着「AI 编辑器」这个最贴近开发者、也最能沉淀训练数据/心智的入口，正在快速阵营化。「模型中立」的空间被挤压。

### 2. 安全信任边界成为商业武器

OpenAI 对 Cursor 断供，用的不是「技术」而是「信任」——服务条款、违约前科、对 Astra 合规使用的问责。信任与安全，已经从「合规成本」变成「可以主动调用的竞争手段」。

### 3. Agent 走向物理世界：能力与标准并进

Google 的 Robotics ER 2 与 Anthropic 的 MHS，一个做「能力」、一个定「规范」，共同标志 **Agent 从屏幕走向物理世界** 是下一阶段的主战场。谁定标准、谁有能力，谁就占据下一轮生态身位。
