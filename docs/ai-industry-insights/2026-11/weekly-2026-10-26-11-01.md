## 📌 本周速览

本周的主旋律只有一个词：**IPO**。Anthropic 在 10/26 正式向 SEC 递交 S-1（拟用代码 `ANT`，Nasdaq 上市，11 月中旬挂牌），市场普遍预期估值区间 $1.5 万亿–$2 万亿，有望成为**人类历史上规模最大的 IPO**——甚至超过 6 月 SpaceX 的 $860 亿募资。这一事件把「AI 头部公司从『烧钱换壁垒』走向『公开市场定价』」的叙事推到了顶点，也让 H1 财报里那个刺眼数字（营收 $163 亿 vs 净亏损 $807 亿，多为非现金项）第一次被放在聚光灯下接受大众检验。

而在 IPO 的强光之外，各家仍在"Agent 化"上贴身肉搏：OpenAI 在 10/26 把轻量级 **GPT-6.1 Terra** 摆上货架（$1/$5），补齐「推理深度」之外的成本曲线；Google 把 **Gemini 4 Argon 从「防御者定向」扩到付费用户**，并一口气堆出 **Gemini Agent、Skills 取代 Gems、Mac 会议纪要、Enterprise 数据查询**等六大企业级工作 Agent 能力；Meta 的三度跳票之作 **Muse Spark** 终于落地，还并购了一家做「Agent 与 Agent 直接谈判」的公司——把「你的订票 Agent 直接对供应商销售 Agent 说话」的图景推向前台。

国产侧本周相对安静，延续性新闻为主：阿里 **Qwen-Image-2.1** 系列（10/9）与智谱 **GLM-Legal**（10/13）继续强化「领域专用化」。但宏观温度计开始报警：IMF 警告 AI 支出或成泡沫拖累全球、CoreWeave 股价单日跳水约 15%（债息逼近 15%）、八州起诉 OpenAI 安全声明。**繁荣的高点与风险的裂缝，正同时被拉满。**

本周（也是全年）最大的事件，是 Anthropic 的公开上市备案。

| 维度 | 内容 |
|------|------|
| 备案 | 10/26 递交 Form S-1（此前 6/1 已有机密备案） |

> 🔍 我的判断：这件事的真正看点不在「是不是最大 IPO」，而在于 **S-1 把一个根本矛盾摆到了台面上**——Anthropic 一边用「科学权威 + 安全可靠」的人设融资，一边在报表里写下 $807 亿的半年亏损。$807 亿里大部分是股份支付与会计计入（非经营性烧钱），但普通投资者和大选周期里的监管者未必会做这个区分。**「为了安全而慢」的叙事，从此要让位于「为了股东而盈利」的纪律**。这是 Anthropic 从「科研机构化公司」走向「上市公司」必须跨越的一步，成败取决于它能否在公开市场里同时守住「负责任 AI」的人设和「扭亏为盈」的路线图。另一个细节值得留意：Ant 这个 ticker 自带「协作、勤勉」的符号感，与 OpenAI「ChatGPT」的品牌走向形成有趣对照——**OpenAI 卖的是产品记忆，Anthropic 卖的是组织记忆。**

## 🔵 二、Google：Gemini 4 Argon 放开付费用户 + 六大「工作 Agent」能力（10月中-下旬）

Google 本周的牌，是把「安全旗舰」从防御者圈层推向大众，同时把 Gemini 改造成一个「带账户、带权限、带预算」的工作 Agent 平台。

### 2.1 Gemini 4 Argon 向付费用户放开

- 10/1 发布、10 月中旬起向付费用户滚动开放，API 折扣价持续到 11 月。
- 最初仅限政府 / 受信网络防御者（Fairwind Program），现扩展到 Gemini 与 Antigravity 付费层。
- 保持 **1M token 输出窗口** + 「最低幻觉率」卖点。

### 2.2 六大企业级工作 Agent 能力

| 能力 | 说明 |
|------|------|
| **Gemini Agent** | 拥有自己的账户、权限与支出上限，可自主行动 |
| **Skills 取代 Gems** | Gems 转型为「技能」，面向任务执行而非话术 |
| **Mac 会议纪要 App** | 本地化、隐私优先的会议转写 |
| **Enterprise 数据查询** | 无需把数据复制到 Google 即可查询 |
| **Vault 对话归档** | 企业合规与留档 |
| **Chat 会议回顾** | 自动生成工作流摘要 |

> ⚠️ 时间线：企业版 Gems 的迁移截止最早在 2027/3/1。

### 2.3 硬件：Gemini Glasses

- 音频层智能眼镜（无屏），秋季出货；合作方三星、Gentle Monster、Warby Parker。
- **同时兼容 iOS 与 Android**——被普遍视为 2026 年「最平台中立」的 AI 硬件。

> 🔍 我的判断：Google 的动作是一套组合拳——**用 Argon 守「安全信任」心智，用 Gemini Agent 抢「企业工作流」心智，用 Glasses 抢「随身交互」心智**。其中「Gemini Agent 带独立账户 + 支出上限」这条最值得盯：它把「Agent 替你花钱」这件事产品化了，等于率先把「授权边界」做成了可配置项，而不是事后兜底。这与 OpenAI 的 rogue agent 问题形成鲜明反差——**Google 把「越权」从风险项做成了产品功能项**。风险在于：Argon 本身的编码等硬能力一直有内部质疑声，「安全叙事」若撑不起「能力叙事」，扩量只会放大落差。
