# 跳槽策略指南

> 从技术准备到 Offer 谈判的全流程实战指南。

---

## 🤔 什么时候该考虑跳槽

### 合理的跳槽信号

| 信号 | 说明 |
|------|------|
| **成长停滞** | 1-2 年没有学到新东西，工作变成重复劳动 |
| **晋升受阻** | 业绩优秀但多次晋升失败，原因不透明 |
| **薪资倒挂** | 新人工资比自己高 30%+，调薪无法弥补 |
| **业务萎缩** | 公司/部门走下坡路，裁员风险高 |
| **价值观冲突** | 公司文化恶化，或与自己价值观严重冲突 |
| **生活变化** | 家庭、健康、城市等客观因素变化 |

### 不建议跳槽的情况

- ❌ 单纯因为"累"（下一家可能更累）
- ❌ 因为一次冲突或一时冲动
- ❌ 为了小幅薪资涨幅（< 20%）
- ❌ 还没满 1 年（除非特殊情况）
- ❌ 逃避当前的问题（问题会跟着你走）

## 📋 跳槽前准备

### 1. 自我评估

**技术能力盘点**：
```
硬技能：
□ 编程语言/框架熟练度
□ 系统设计能力
□ 性能优化经验
□ 故障排查能力

软技能：
□ 沟通表达能力
□ 项目管理经验
□ 团队协作能力
□ 业务理解深度
```

**职业目标澄清**：
- 下一份工作最看重什么？（技术成长 / 薪资 / 工作生活平衡 /  title）
- 3-5 年后的职业目标是什么？
- 能接受的最大风险是什么？（创业公司倒闭 / 大厂螺丝钉）

### 2. 市场调研

**薪资调研**：
- [Levels.fyi](https://www.levels.fyi/) — 海外大厂职级薪资
- [脉脉](https://maimai.cn/) — 国内公司薪资爆料
- [OfferShow](https://www.offershow.com/) — 校招/社招薪资
- 猎头朋友、前同事

**公司调研**：
- 业务前景：财报、行业趋势、竞争对手
- 技术氛围：GitHub、技术博客、开源贡献
- 工作强度：脉脉、知乎、Glassdoor
- 面试体验：牛客网、一亩三分地面经

### 3. 简历准备

**技术简历原则**：

1. **量化成果**
   - ❌ "负责订单系统开发"
   - ✅ "设计并落地订单系统，支持日活 100w 用户，QPS 峰值 5000，P99 延迟 < 200ms"

2. **STAR 法则**
   - **S**ituation：背景
   - **T**ask：任务
   - **A**ction：行动
   - **R**esult：结果

3. **关键词优化**
   - 根据 JD（职位描述）调整关键词
   - 确保 ATS（简历筛选系统）能识别

**简历结构**：
```
1. 个人信息（姓名、电话、邮箱、GitHub/博客链接）
2. 技术栈（按熟练度分类）
3. 工作经历（倒序，每段 3-5 个 bullet points）
4. 项目经历（重点写 2-3 个最有代表性的）
5. 教育背景（社招可简化）
6. 其他（开源贡献、技术分享、专利等）
```

## 🎯 面试准备

### 技术面试

**算法**：
- LeetCode 200-300 题（重点：Top 150）
- 分类刷题：数组、链表、树、动态规划、回溯
- 重点练习：medium 难度，能写出最优解并分析复杂度

**系统设计**：
- 学习资源：《Designing Data-Intensive Applications》、System Design Primer
- 练习题目：设计 Twitter、设计 URL Shortener、设计 Rate Limiter
- 回答框架：需求分析 → 估算 → 高层设计 → 详细设计 → 扩展性

**项目深挖**：
- 准备 2-3 个项目的详细讲解
- 面试官会问：为什么这样设计？如果重来会怎么改？遇到什么挑战？

### 行为面试 (Behavioral)

**常见题目**：
- 讲一个你解决过的最困难的技术问题
- 讲一次你和同事的分歧，怎么解决的
- 讲一个你失败的项目，学到了什么
- 你为什么离开上一家公司

**回答框架 (STAR)**：
```
Situation：当时我们在做 XX 项目，面临 YY 挑战
Task：我的任务是...
Action：我做了...（重点讲"我"的行动，不是"我们"）
Result：结果是...（量化）
Reflection：如果重来，我会...
```

### 反问环节

**必问问题**：
1. 这个职位的日常工作是什么样的？
2. 团队目前面临的最大挑战是什么？
3. 成功胜任这个职位，3-6 个月内需要达成什么？
4. 团队的技术栈和工程文化是怎样的？
5. 直属领导的风格和管理方式？

**避雷问题**：
- 加班多吗？（可以问"工作节奏"）
- 我能拿多少薪资？（等 HR 面再谈）

## 💰 Offer 谈判

### 谈判原则

1. **信息就是力量**
   - 了解该公司的薪资范围
   - 了解你的市场价值
   - 有多个 Offer 时谈判筹码最大

2. **不要先出价**
   - 对方问期望薪资："根据我的调研，这个职位的市场范围是 X-Y，我相信贵司有合理的薪酬体系"
   - 必须说数字时，给一个范围，上限是你真正想要的

3. **总包思维**
   - 现金：基本工资
   - 股权/期权：行权价、归属期、回购政策
   - 奖金：年终奖、绩效奖、签字费
   - 福利：公积金比例、补充医疗、带薪假

### 谈判话术

**薪资低于预期**：
> "感谢 Offer，我对团队和项目都很感兴趣。不过目前我还有一个 Offer 在考虑，总包是 XX。如果贵司能匹配到 YY，我会毫不犹豫地选择加入。"

**想要更多股权**：
> "我更看重长期发展，能否在股权部分做一些调整？我可以接受基本工资稍低一些。"

**需要思考时间**：
> "感谢 Offer，我需要和家人商量一下，能否给我 3 天时间回复？"

## ⚠️ 跳槽风险与应对

### 风险 1：新公司不如预期

**应对**：
- 面试时多了解团队和业务
- 入职前和未来的同事聊聊
- 设定试用期观察清单

### 风险 2：适应期压力

**应对**：
- 前 3 个月多观察少发言
- 快速建立信任：先赢一个小胜利
- 主动约 1on1，了解期望

### 风险 3：频繁跳槽的简历污点

**应对**：
- 尽量每段工作 > 2 年
- 如果确实短，准备好解释（业务调整、公司裁员等客观原因）

## 📅 跳槽时间线

```
T-2 月：自我评估、市场调研、更新简历
T-1 月：开始投递、准备面试
T 周：密集面试（建议每周不超过 3 场，避免 burnout）
T+1 周：收 Offer、谈判
T+2 周：确定 Offer、提离职
T+1 月：交接工作、办理离职
T+2 月：入职新公司
```

## 💡 我的思考

1. **跳槽是手段，不是目的**：不要为了跳槽而跳槽。每次跳槽都应该有明确的职业目标。

2. **最好的跳槽是"内部跳槽"**：在同一家公司换团队、换项目，风险最小。如果内部没有机会，再考虑外部。

3. **薪资涨幅不是唯一指标**：技术成长、业务影响力、工作生活平衡同样重要。30% 的涨幅但学不到东西，不如 15% 但能快速成长。

4. **国内跳槽的特殊注意**：
   - 竞业协议：签 Offer 前看清楚竞业范围
   - 公积金：问清楚缴纳基数和比例
   - 期权：问清楚行权价、归属期、离职处理

5. **一个实用建议**：每年更新一次简历，即使不打算跳槽。这迫使你回顾一年的成长，也能及时发现"成长停滞"的信号。
